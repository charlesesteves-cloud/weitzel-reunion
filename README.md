# Weitzel Family+ Reunion Survey

## Deploy to Vercel

1. Go to github.com and create a new repository called `weitzel-reunion`!! !
2. Upload all these files to the repository (drag and drop works)
3. Go to vercel.com, click "Add New Project"
4. Import your `weitzel-reunion` GitHub repository
5. Click "Deploy" — no settings to change
6. Once deployed, go to your project settings → Storage → Create KV Store (free)
7. Link the KV store to your project and redeploy

That's it! Share the URL Vercel gives you with the family.

## To update the survey later
Just edit the files on GitHub and Vercel will auto-redeploy.
